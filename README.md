# nrzStore

**English** — Public app store for umbrelOS with the open-source nrz apps. Add this repository's
URL under *App Store → Community App Stores* in umbrelOS.

**Deutsch** — Öffentlicher App-Store für umbrelOS mit den Open-Source-nrz-Apps. Die URL dieses
Repos in umbrelOS unter *App Store → Community App Stores* hinzufügen.

**Español** — Tienda de aplicaciones pública para umbrelOS con las apps nrz de código abierto.

Most apps download their program from nrzGit and depend on `nrz-git` (from nrzPrivatStore).
